# Pisex Game Utils — компиляционный зонд (НЕ ДЛЯ УСТАНОВКИ)

Это **не рабочий выпуск**. В используемой версии SDK отсутствуют определения `CServerSideClientBase` и `IEntityResourceManifest`.

## Что изменено

- Исходный функционал `ProcessTick`, `ProcessStringCmd`, `AddResource` **сохранён в исходниках** за условием `PISEX_PRIVATE_ABI_VERIFIED`; при значении `0` он не выполняется.
- Сохраняются доступные хуки событий игроков, в том числе `ClientConnect` и `ClientDisconnect`, а также исходный HUD-код.
- Исправление расчёта размера ссылочных аргументов KHook остаётся в GitHub Actions.
- В имени выходного артефакта явно указано **COMPILE-PROBE-DO-NOT-DEPLOY**.

## Что НЕ работает при `PISEX_PRIVATE_ABI_VERIFIED=0`

- Перехват `ProcessTick`.
- Перехват `ProcessStringCmd`.
- Внесение ресурсов через `IEntityResourceManifest::AddResource` (ресурсы HUD могут не загрузиться).

Включать `PISEX_PRIVATE_ABI_VERIFIED=1` **нельзя**: это сохранённый старый код, для которого SDK не предоставляет нужные типы и API. Вычислять наугад адреса/смещения/номера виртуальных методов опасно.

## Проверка

Загрузите все файлы в репозиторий, затем запустите `Build Pisex Game Utils - full KHook API 18 attempt`. Даже если компиляция пройдёт, **не устанавливайте полученный .so** на MyArena: требуется отдельная реализация и испытание приватных ABI функций.

Задача данного архива — получить следующий точный список проблем компиляции, не маскируя их фальшивыми интерфейсами.
