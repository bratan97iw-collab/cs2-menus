# Pisex Game Utils — единый комплект исходников (04.11.2026)

Это полный архив репозитория, а не очередной отдельный `utils.cpp`.

## Изменено вместе

- `utils.cpp` — KHook `ProcessUsercmds` приведён к `const CNetMessagePB<CCLCMsg_Move>&` по интерфейсу `IServerGameClients` из используемого SDK.
- `utils.h` и `include/players.h` — объявление слушателя обновлено одновременно с обработчиком, чтобы не возникло рассогласования заголовков.
- `utils.cpp` — слот для `CheckTransmit` читается через `CCheckTransmitInfoHack` (структура из Pisex SchemaEntity), поскольку в текущем `CCheckTransmitInfo` SDK такого поля нет. **Это совместимость по смещению в памяти, она не подтверждена на игровом сервере.**
- Все прочие файлы проекта оставлены в комплекте.

## Важно: это НЕ выпущенный бинарник

Сборка ПОКА не подтверждена. По последнему GitHub Actions логу до исправлений оставались незавершённые вопросы: `CServerSideClientBase` (неполный класс), `CNETMsg_Tick_t`, `CNETMsg_StringCmd_t`, `GameSessionConfiguration_t` и `IEntityResourceManifest`.

Совместимость ABI для сторонних, уже собранных модулей Pisex после изменения аргумента `ProcessUsercmds` также не подтверждена. Перед установкой на MyArena обязательны успешная компиляция, проверка запуска на тестовом сервере, в особенности `CheckTransmit` и HUD. **Не устанавливать на рабочий сервер по этому архиву.**

## Применение

Используйте распакованное содержимое архива вместо содержимого старой копии репозитория (сохранив `.git` из клона). Не смешивайте отдельные ZIP-патчи из прошлых ответов. Уже имеющийся workflow `.github/workflows/build_pisex_khook_api18.yml` запускает сборку.

Для полного устранения оставшихся ошибок потребуется сверить реализации сетевых классов с SDK/движком, а не выключать хуки ради успешной компиляции.
